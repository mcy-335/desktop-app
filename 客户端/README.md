# LetterPet Live2D 正式版

此文件夹是完整项目副本，与仓库根目录的旧版独立。

## 运行

双击本文件夹的 `启动桌宠.bat` 或 `LetterPet.exe`。保留旁边的 `assets` 和 `live2d-runtime`。
需要 Windows 10/11 x64；如缺少依赖，请安装 Microsoft Visual C++ x64 运行库。
在其他程序打字即可驱动动作；左键拖动人物，右键打开缩放和退出菜单。
本版沿用正式桌宠的用户设置和单实例机制，不建议同时运行旧版。

从解压、自动测试、独立演示库到答辩操作的完整步骤见 [交付说明](交付说明.txt)。

## 账号与同步

启动程序会先打开账号窗口。手动注册或登录前须勾选「自动登录」，然后输入账号和密码。点密码框旁的「显示 / 隐藏」可切换明文或圆点。下次启动时，已授权的会话通过服务端验证后可自动登录。升级前的「记住登录」需要重新勾选一次。右键桌宠打开「我的账号」可同步任务、专注记录、课表、养成和成就。退出登录会关闭桌宠及其面板，并直接返回登录窗口。管理员创建、服务启动和跨电脑连接方式见 [账号服务说明](../服务端/server/README.md)。

「我的账号」会填入本机保存的登录密码，默认遮挡，点「显示」查看；窗口失去焦点后恢复遮挡。密码与会话凭据一起由 Windows DPAPI 加密保存，退出登录时删除。旧版仅保存登录凭据的用户需要退出后重新登录一次，才能查看密码；服务端密码哈希不用于还原密码。

任务面板仅在内容或状态变化时更新控件。五套 DIY 场景保持加宽的桌面，人物大小与键鼠操作位置不变。

配饰改为人物周围的六个悬挂位置，带有短挂线、轻微浮动和摆动；DIY 预览同步显示装备与试戴效果。原版纸牌保留，阿蒙的大帽子和乌鸦区域单独避让。新增琥珀星灯、银杏叶坠、封蜡来信透明素材，部分旧摆件转为金边卡牌；桌面和桌前饰框不再摆放商城配饰。

## 专注代币与商城

用新版桌宠在线专注，有效专注每满 1 分钟获得 1 枚代币，每天最多计入 180 分钟。点击「我的账号 → 打开商城」，用同一个普通账号登录。兑换配饰后点击「应用到桌宠」。左上悬灯、右上叶饰、左下时砂、左侧悬牌、右侧信笺和右下悬牌各有固定位置，可同时显示六件，同位置可更换。也可以兑换专注收藏卡。

「专注与养成」显示本轮到账、距离下一枚代币的时长和记账状态。商城里的「在桌宠上试戴」会临时覆盖该配饰的位置，约一分钟后恢复。「我的配饰」可查看和使用已兑换物品。

专注面板以「有效专注 / 目标时长」为主。阅读、听课无需持续操作键鼠；主动暂停、锁屏或休眠时停止累计，锁屏或休眠恢复后点击「继续」。亲密度每累计 10 分钟有效专注增加 1 点，零头跨轮保存。中途结束保留已累计的学习时长、亲密度和已确认代币；完整完成目标时长才增加完成轮次，不再固定奖励亲密度 +3。代币仍需服务端在线确认，并受每日额度限制。

在商城可查看代币流水和云端存档历史。管理员可查看操作记录，并创建或恢复数据库快照。 [账号服务说明](../服务端/server/README.md)

## 窗口置顶

右键桌宠或托盘图标勾选「窗口置顶」后，桌宠会在切换普通 Windows 应用时保持在前方，并优先于「全屏时自动隐藏」设置。右键菜单打开时显示在角色上方。专注、本地音乐等功能面板可以像普通窗口一样切换，操作面板及其对话框时，桌宠会让到它们后面。

## 专注应用白名单

在「专注与养成」中打开「应用白名单」，点「添加应用」查看当前打开的应用和开始菜单里可识别的程序。可按名称或路径搜索，双击列表项或点「加入白名单」即可。找不到时，可以先打开该应用再点「刷新」，也可通过「浏览文件」选择程序或快捷方式。

勾选限制后，名单外应用有 3 秒切换宽限，超过后暂停有效专注计时并提示，返回允许应用后自动继续；连续切换名单外应用不会重置宽限。桌宠会在可识别的名单外窗口稳定处于前台时将它最小化。操作右键菜单、任务栏或托盘时会暂缓最小化处理。暂停、休息和结束专注时可以正常切换应用。名单和开关保存在本机。

## 外观 DIY

右键桌宠或托盘图标，打开「外观 DIY」。在「Live2D 角色」中选择原版桌宠、阿蒙（Amun）、知更鸟（Robin）或桑多涅（Sandone）。四个角色都可以与红金、午夜蓝、奶油白、森林绿和高对比主题搭配。也可以导入 PNG 或 JPG，之后点「使用所选模型」返回下拉框选中的角色。勾选「移除绿幕背景」可预览去背效果。

在预览里拖动角色并调整大小。导入的图片可以选择呼吸、轻晃或点击弹跳。点「应用外观」后，桌宠换成所选角色与主题，图片和选择保存在本机。点「恢复原版桌宠」可回到原版场景。请保留程序旁的 `assets/diy` 和 `assets/live2d/character-models` 目录。

## 红金界面与字体

功能面板、课程提醒、角色提醒和右键菜单统一采用深酒红、柔金色界面。中文使用 MiSans，计时与数值使用 Segoe UI。专注面板调整为大号计时、分列养成状态；原文案、控件入口和业务规则保留。

`assets/fonts/MiSans-Regular.otf` 随程序私有加载，不安装到 Windows；请保留同目录中的字体许可和说明。字体不可用时回退到本机可用的中文界面字体。

红金界面的历史自动检查结果见 `tests/results/red-gold-ui/`。当前版测试步骤见交付说明。

## 本版内容

- Cubism joints-v2 模型，B 版 85% 键盘及原信封键帽。
- 真实键鼠输入驱动肩、肘、腕；保留眨眼。
- 86 个逻辑键、60 个可见键帽；无可见键帽的按键不误亮其他键。
- 自然可达范围内跟随，不保证全键精准触碰，不拉长手臂。
- 最新按键优先，组合键分别反馈；鼠标整手轻点。

## 源码与工程

- `src/`：现有 C 主程序和 C++ Live2D 接口。
- `live2d-preview/arm/`：正式手臂、键帽和输入逻辑。
- `assets/live2d/runtime/pet/`：运行模型、纹理、眨眼动作。
- `assets/live2d/arm-rig-v1/pet-arm-rig-joints-v2.cmo3`：最终可编辑工程。
- `live2d-runtime/licenses/`：随附的 SDK/Core 许可说明。

编译需另行安装 MinGW-w64、Visual Studio C++ 工具和 Cubism SDK for Native；完整 SDK 不包含在此包。
在本文件夹执行 `./build.ps1 -SdkPath '你的 Cubism SDK 路径'`。
`live2d-preview` 同时包含历史独立预览源码，正式桌宠入口为根目录 `LetterPet.exe`。

本版本程序级集成检查已通过。运行 `./LetterPet.exe --integration-test` 可重新执行，不截屏。
版本及运行文件 SHA256 见 `live2d-release.json`，本包完整文件清单见 `SHA256SUMS.json`。
