LetterPet uses MiSans for its Chinese user interface and Segoe UI for numeric displays.

MiSans Regular is included unmodified and is loaded privately for the current process.
It is not installed into Windows. Copyright and license are retained in the font metadata
and the accompanying MiSans-LICENSE.pdf.

MiSans copyright belongs to Xiaomi Inc. and its respective licensors.
Official font project and license: https://hyperos.mi.com/font/zh/

If the bundled font cannot be loaded, the interface falls back to an available local
MiSans, Noto Sans SC or Microsoft YaHei UI font. Segoe UI is provided by Windows.
