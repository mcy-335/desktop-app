# LetterPet 账号服务

服务端需要 Python 3.10 或更新版本，使用 SQLite 存储账号与存档。

## 本机试用

双击 `server\start-local.cmd`，或在项目根目录的 PowerShell 中运行：

```powershell
python .\server\letterpet_server.py serve
```

打开桌宠程序，在启动账号窗口的「服务地址」输入 `http://127.0.0.1:8765`。新用户填写账号、密码和确认密码，勾选「自动登录」，点击「注册」即可创建账号并启动桌宠。账号名以小写英文字母开头，长度 3–32，支持小写英文字母、数字、点、下划线和连字符。密码长度 8–128。

已有账号填写账号和密码，勾选「自动登录」后点「登录」。浏览器打开服务地址可以查看服务状态。登录后会读取云端进度，运行期间约每分钟同步一次，也可以点「立即同步」。首次登录想把当前单机进度带到新账号，可勾选「首次登录导入本机进度」，仅在该账号的本机和服务端都为空时执行。

用 A 登录后完成一轮专注，再点「立即同步」。退出登录会关闭桌宠并返回登录窗口。在该窗口登录 B 可以看到独立进度。另一台电脑安装同一版本客户端并连接同一个服务地址后，登录 A 可以同步 A 的记录。

## 同步与账号管理

- 同步范围包括任务、专注统计、养成、成就、台词和课程表。专注倒计时仍在客户端运行。音乐库、桌面位置、快捷键和外观素材保留在各台设备上。
- 已登录账号的本机缓存独立保存。桌宠启动后临时断网可以继续操作，重连后同步。两端分别修改养成存档和课表时，新版客户端可自动合并。同一存档文件在两端都有不同修改时，点「立即同步」选择本机或云端版本。使用云端版本前，本机上一份存档会保留在另一个本机存档槽。
- 在商城的「云端存档」可查看当前版本及最近 12 个历史版本。恢复旧版本会创建一个新版本，恢复前的版本也会保留。恢复后在桌宠中点「立即同步」，遇到冲突时选择使用云端。
- 「自动登录」由 Windows DPAPI 保护登录令牌。再次启动时，已有会话通过服务端验证后才能启动桌宠。改密或服务端停用账号会撤销旧会话。服务端数据库默认位于 `server/data/letterpet.sqlite3`，应按存档备份。

## 用户登录与商城

在服务首页点「用户登录与商城」，或在桌宠右键的「我的账号」里点「打开商城」。普通用户用桌宠账号登录 [专注商城](http://127.0.0.1:8765/shop)。

- 新版桌宠定期上报有效专注计时。服务端用两次上报之间的时间约束可计入时长，同一账号同时只记一台客户端。每累计满 1 分钟给 1 枚代币，零头继续累计，每天最多计入 180 分钟，按北京时间午夜重置每日额度。
- 阅读、听课不要求键鼠活动。新版客户端统一使用有效专注时长推进倒计时、学习统计、亲密度和代币上报。白名单外停留超过 3 秒宽限后停止累计，返回允许应用后自动继续。主动暂停、锁屏、休眠和休息不计入；锁屏或休眠恢复后需主动继续。服务端仍排除长时间断网的间隔，保留每日额度和单设备记账限制。
- 代币不足一分钟的零头在账户中跨轮累计；亲密度每 10 分钟 +1，零头随客户端存档保存并可云同步。中途结束保留已累计的有效时间与收益，只有完整完成目标时长才增加完成轮次。
- 升级后的服务仍支持旧版客户端的账号、存档和配饰查询。赚取代币需要新版客户端。
- 「专注与养成」显示服务端确认的本轮到账数量、距下一枚所需秒数和记账状态。暂停后继续同一轮会保留该轮计数。
- 兑换前可点「在桌宠上试戴」，同一账号运行中的新版桌宠会在下次同步显示试戴效果。试戴约一分钟后结束，也可提前结束，已保存的配饰会恢复。
- 兑换后，桌牌可以应用到桌宠或卸下。客户端会在下一次自动查询时更新配饰。星光桌牌、莓心桌牌和月牙桌牌共用一个配饰位置，专注收藏卡保存在账号内。
- 「我的配饰」集中显示已兑换的桌牌和收藏卡，可直接应用、卸下和试戴。
- 代币、已兑换物品和当前配饰按账号保存。停用账号会撤销商城登录，删除账号会一并清除商城数据。
- 「代币流水」记录入账、兑换和变动后的余额。升级前的余额作为期初余额保留。

## 管理后台

升级服务端时先停止旧服务。新版使用原数据库，并从已有云端存档补齐各账户的成就和称号。

1. 启动账号服务。如果数据库还没有管理员，启动窗口会在 `First administrator setup code:` 后显示一次性注册码。
2. 在服务端电脑打开 [管理后台](http://127.0.0.1:8765/admin)，点击「注册管理员」。
3. 填写账号、两次密码和注册码。注册成功后会直接进入后台，注册入口随即关闭。

已有管理员可以直接登录。普通用户在 Windows 客户端注册和登录。

- 点击账号可查看最近同步的桌宠进度、学习任务、每日专注记录和课程表。点击每个账户旁的「查看成就」，可单独查看该账户的 8 项成就、解锁条件和当前称号。客户端可用「立即同步」上传最新进度。
- 停用会撤销该账号的现有会话，并阻止再次登录。重新启用后，用户可登录并继续使用原云端数据。
- 删除时需要输入完整账号名。删除会移除该账号、云端存档、成就和会话。设备上的本地缓存及已有备份由各自的持有人管理。
- 账户详情可查看该账户的代币流水。后台「操作记录」会记录管理员的账户操作、备份和恢复，含操作者、目标、时间和结果。

需要添加更多管理员时，可在服务端运行 `create-admin` 命令。以下命令也可用于维护账号。

```powershell
python .\server\letterpet_server.py create-admin pet_admin
python .\server\letterpet_server.py list-users
python .\server\letterpet_server.py create-user demo_a
python .\server\letterpet_server.py set-password demo_a
python .\server\letterpet_server.py disable demo_a
python .\server\letterpet_server.py enable demo_a
```

## 商城配饰

「当前摆放」显示六个固定位置。同一个位置的商品可以更换，其他位置可以同时使用。试戴约一分钟，只临时替换试戴商品所在的位置。已有桌牌和收藏会保留。

商城标出了红金、午夜蓝、奶油白、森林绿和高对比的搭配建议，任意主题仍可自由混搭。新增配饰需搭配新版客户端。更新服务端时请保留项目中的 `assets/rewards` 目录，商城和客户端使用同一套商品图片。

## 数据库备份与恢复

管理员可在「备份与恢复」创建 SQLite 在线快照。快照保存在数据库旁的 `letterpet.sqlite3.backups` 目录。将快照复制到服务端电脑以外的位置可用于灾难恢复。快照包含账号、存档、成就、钱包、流水和配饰。

选择快照恢复整库时，服务端会先创建一份恢复前快照。成功后，用户和管理员需要重新登录。客户端会为恢复后的服务重新建立缓存，避免旧缓存自动覆盖恢复结果。

也可以在项目根目录运行命令。数据库损坏时，可用 `--db` 指定一个新文件恢复，再用同一个 `--db` 路径启动服务。

```powershell
python .\server\letterpet_server.py backup
python .\server\letterpet_server.py --db .\server\data\recovered.sqlite3 restore .\你的快照.sqlite3
python .\server\letterpet_server.py --db .\server\data\recovered.sqlite3 serve
```

## 跨电脑连接

服务端默认只监听本机。跨电脑使用时，配置客户端信任且域名匹配的 HTTPS 证书，再启动：

```powershell
python .\server\letterpet_server.py serve --host 0.0.0.0 --port 8765 --cert .\fullchain.pem --key .\privkey.pem
```

在客户端填入对应的 HTTPS 地址，例如 `https://pet.example.com:8765`。把证书私钥和 SQLite 数据文件放在仅服务管理员可访问的目录。

### 使用 Tailscale Serve

如果 Tailscale Serve 已将 `https://你的电脑名.你的网络名.ts.net` 转发到 `http://127.0.0.1:8876`，重启 LetterPet 服务端时加上对外的 HTTPS 地址。沿用现有的 `--db` 路径和端口。

```powershell
python -B .\server\letterpet_server.py --db .\server\data\online-test.sqlite3 serve --port 8876 --https-proxy-origin https://你的电脑名.你的网络名.ts.net
```

商城和管理后台会使用配置的 HTTPS 地址校验表单来源，并为该地址设置 Secure Cookie。服务端仅从回环连接读取代理提供的 `X-Forwarded-Proto` 和 `X-Forwarded-Host`，并校验它们与配置匹配。本机仍可通过 `http://127.0.0.1:8876` 访问。

## 悬挂配饰更新

本版商城配饰使用六个悬挂位置，客户端需要同时更新。新增琥珀星灯、银杏叶坠、封蜡来信素材；其商品编号仍为 lamp、fern、ivorytea，价格及已有购买、装备记录保持不变，无须迁移数据库。部署时复制 server 代码和 assets/rewards 文件夹，沿用原数据库、端口和 HTTPS 参数重启服务。不要用空数据库替换已有数据库。
