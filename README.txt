桌宠
====

Windows 原生桌面宠物，核心程序使用 C11 和 Win32 API 编写。
运行时不需要 Electron、Node.js、Python 或额外下载的图形库。

启动
----
1. 在 GitHub 仓库页面选择 Code -> Download ZIP，完整解压。
2. 打开 c-desktop-pet 文件夹。
3. 双击 LetterPet.exe 或“启动桌宠.bat”。
4. 请保留 exe 旁边完整的 assets 文件夹，不要只下载 exe。

运行环境：64 位 Windows 10 / Windows 11；当前版本主要在开发电脑上验证。
首次启动默认显示在桌面左下方。右键角色打开菜单；托盘可显示/隐藏桌宠。
关闭窗口会隐藏桌宠，彻底退出请使用菜单中的“退出桌宠”。

主要功能
--------
- 透明无边框显示、拖动、置顶、鼠标穿透。
- 50%、75%、100%、125%、150% 五档大小。
- 86 键布局：87 键无数字区布局去掉右侧菜单键，左右修饰键独立。
- 全局键鼠响应、键帽按压反馈、键盘手跟随和鼠标三键动作。
- 固定手掌比例的关节变形动画、眨眼和随机表情。
- 纸牌、玩偶点击后的放大与发光。
- 红金配色菜单、托盘、开机启动选项、设置保存、单实例运行。
- 只读进程列表、中文描述/别名、原进程名、PID、CPU、内存及排序。

快捷键
------
Ctrl + Alt + Shift + P：切换鼠标穿透。
Ctrl + Alt + Shift + G：切换游戏模式。
若与其他程序的快捷键冲突，可通过托盘菜单操作。

游戏模式使用普通窗口置顶和鼠标穿透，不进行游戏注入。
不能保证覆盖所有独占全屏游戏，也不能保证所有权限/游戏环境都能接收输入。
键鼠输入用于即时动画，程序不保存输入文本或按键历史。
本机设置保存在 %LOCALAPPDATA%\LetterPetC\settings.ini，不随仓库发布。

从源码编译
----------
安装 MinGW-w64 GCC，并将 gcc.exe 所在目录加入 PATH。
在本文件夹打开 PowerShell，执行：
  powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
输出为 LetterPet.exe。重新编译前请退出正在运行的桌宠。

程序自检
--------
执行：
  .\LetterPet.exe --self-test
自检生成 self-test.log 和 test-*.bmp，不更改用户设置。
包含 86 键模型、按键释放、短鼠标点击、手掌对齐、进程采样、表情和缩放检查。
自检并不代表已完成游戏兼容、多屏、高 DPI 和长期稳定性验证。

目录
----
src/main.c       窗口、菜单、输入、设置和运行管理
src/animation.c  键位、动作状态和双臂变形
src/render.c     透明画面及软件三角形渲染
src/monitor.c    只读进程采样及监控面板
src/pet.h        公共类型和接口
assets/         运行必需的预乘 BGRA 素材
tools/prepare-assets.cjs  原工程的制作期素材导出工具

assets 已包含导出的素材，正常运行和编译 C 程序均无需运行导出工具。
该工具仅供原 Electron 工程环境中重新导出素材，独立下载本文件夹后不能直接运行。
