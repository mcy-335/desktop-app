桌宠
====

Windows 原生桌面宠物：C11 / Win32 主程序 + C++17 Live2D 渲染模块。
运行时不需要 Electron、Node.js、Python 或额外下载的图形库。

启动
----
1. 在 GitHub 仓库页面选择 Code -> Download ZIP，完整解压。
2. 打开 c-desktop-pet 文件夹。
3. 双击 LetterPet.exe 或“启动桌宠.bat”。
4. 请保留 exe 旁边完整的 assets 和 live2d-runtime 文件夹，不要只下载 exe。

运行环境：64 位 Windows 10 / Windows 11；当前版本主要在开发电脑上验证。
首次启动默认显示在桌面左下方。右键角色打开菜单；托盘可显示/隐藏桌宠。
关闭窗口会隐藏桌宠，彻底退出请使用菜单中的“退出桌宠”。

Live2D 手臂接入版（2026-10-31）
---------------------------
默认使用 pet-arm-rig-joints-v2 模型，保留 B 版 85% 键盘布局、信封键帽和原眨眼。
全局真实键盘输入驱动肩、肘、腕及辅助关节；鼠标三键驱动整手轻点。
运行时使用模型参数和原键帽图案的按压/回弹反馈，不播放预录视频。
单击人物会短暂闭眼；拖动不会触发该反馈。隐藏期间停止绘制。
右键“切换为原版键鼠互动”可恢复旧版手臂、键帽、表情和纸牌/玩偶互动；
再选“切换为 Live2D 手臂互动”返回新模式。模式随设置保存。

两种模式共用拖动、五档缩放、置顶、穿透、游戏模式、托盘和 CPU/GPU 面板。
C 主程序保留 86 个逻辑键，Live2D 原画映射 60 个可见键帽，两者不是同一统计口径。
没有可见键帽的按键不点亮其他键；数字小键盘不冒充主键盘或导航键。
组合键分别显示反馈，手只跟随最新输入；快速输入不排队补做旧动作。
手臂保持自然绑定范围，超出范围时靠近最近可达位置，不保证全键精准触碰。
到位且键仍按住时加入手部下压；没有独立手指动画。非美式标点布局可能不同。
下面的随机表情和物件互动仍属于原版互动模式。

Live2D 加载/绘制失败会提示错误并恢复原版显示，而不是黑屏退出。
错误记录在 live2d-host.log；SDK 日志在 live2d-runtime\live2d.log。
另一台电脑若缺少依赖，需要安装 Microsoft Visual C++ x64 运行库。
此文件夹是完整独立的发布副本，可与仓库旧版并列保存。运行请使用本文件夹的 LetterPet.exe。

主要功能
--------
- 透明无边框显示、拖动、置顶、鼠标穿透。
- 50%、75%、100%、125%、150% 五档大小。
- 86 键布局：87 键无数字区布局去掉右侧菜单键，左右修饰键独立。
- 全局键鼠响应、键帽按压反馈、键盘手跟随和鼠标三键动作。
- 固定手掌比例的关节变形动画、眨眼和随机表情。
- 纸牌、玩偶点击后的放大与发光。
- 红金配色菜单、托盘、开机启动选项、设置保存、单实例运行。
- 只读资源面板：顶部显示 CPU、内存、GPU、主要应用四张卡片，默认“主要进程”精简视图，可切换到“全部进程”。
- GPU 通过 Windows PDH 系统计数器每约 1.5 秒采样，不需要额外安装显卡工具。
- 同一物理 GPU 引擎的各进程负载先合计，再取所有显卡中最忙的引擎，不把不同引擎简单相加。
- GPU 首次显示“采样中”，驱动/系统未提供有效计数时显示“暂不可用”并定期重试；有效的空闲读数才显示 0%。
- 主要视图最多 10 项，有窗口的应用优先，补充 CPU ≥ 1% 或内存 ≥ 200 MB 的后台程序。
- 按软件归属合并主程序与辅助组件，显示合计占用与进程数；全部视图仍保留原始进程名和 PID。
- 归属依据包含安装路径、经过创建时间校验的父子关系及明确的组件规则。支持微信 / WeChatAppEx、QQ / QQEX 等。
- WebView 等共享运行时按实际宿主分开汇总，不因使用同一个 exe 就跨软件合并。
- Codex 的后台与 node_repl 多层辅助链通过已验证的桌面归属及当前用户的组件路径合并；独立终端启动的 codex.exe 保持分开。
- 由应用打开的独立可见软件、归属不明或路径无法读取的进程不强行合并。
- 已验证的归属在辅助进程存续期间保留；父进程退出不会立即拆散分组，PID 重用不会沿用旧归属。
- 顶部 CPU / 内存为整机使用率；合并内存为工作集之和，共享页可能重复计入。
- “≥”表示仅合计能读取的数据，“—”表示正在采样或权限受限。
- 保留中文描述/别名、原进程名、CPU、内存及点击表头排序。

快捷键
------
Ctrl + Alt + Shift + P：切换鼠标穿透。
Ctrl + Alt + Shift + G：切换游戏模式。
若与其他程序的快捷键冲突，可通过托盘菜单操作。

游戏模式使用普通窗口置顶和鼠标穿透，不进行游戏注入。
不能保证覆盖所有独占全屏游戏，也不能保证所有权限/游戏环境都能接收输入。
键鼠输入用于即时动画，程序不保存输入文本或按键历史。
本机设置保存在 %LOCALAPPDATA%\LetterPetC\settings.ini，不随仓库发布。

从源码编译
----------
安装 MinGW-w64 GCC，并将 gcc.exe 所在目录加入 PATH。
Live2D 模块另需 Visual Studio 2022/2026 的 C++ 桌面开发工具、Windows SDK、
Cubism SDK for Native。默认 SDK 路径为 D:\CubismSdkForNative-5-r.5。
在本文件夹打开 PowerShell，执行：
  powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
输出为 LetterPet.exe。重新编译前请退出正在运行的桌宠。
只更新 C 主程序、不重建已有的 Live2D DLL，可运行 .\build.ps1 -SkipLive2D。
可用 -SdkPath 指定 SDK 路径，用 -OutputPath 指定候选 exe 的输出位置。
DLL 通过固定 C ABI 连接 MSVC 与 MinGW，不跨模块传递 C++ 对象或分配内存。

程序自检
--------
手臂集成检查（不截屏、不更改用户设置）：
  .\LetterPet.exe --integration-test
输出 integration-test.log，覆盖连续输入、长按、组合键、未映射键、鼠标三键、
眨眼、五档尺寸、透明通道和窗口位置变换，并检查测试进程正常退出。
程序级检查不代替实机键鼠操作、拖动与视觉验收。

原完整自检（包含输出截图）：
执行：
  .\LetterPet.exe --self-test
自检生成 self-test.log 和 test-*.bmp，不更改用户设置。
包含 86 键模型、按键释放、短鼠标点击、手掌对齐、进程采样、表情和缩放检查。
同时检查软件分组、共享运行时隔离、PID 重用、父进程退出、占用合计及完整视图还原。
GPU 自检覆盖多显卡/引擎合计、无效读数、空闲 0%、不可用状态、数值范围及本机实际采样。
Live2D 自检覆盖两轮眨眼、真实像素变化、透明/半透明像素和预乘 BGRA、
五档画布大小、点击闭眼及缺失模型后的资源重建，并输出 test-live2d-*.bmp。
可用 --self-test --legacy 仅运行原版测试。
自检并不代表已完成游戏兼容、多屏、高 DPI 和长期稳定性验证。

目录
----
src/main.c       窗口、菜单、输入、设置和运行管理
src/animation.c  键位、动作状态和双臂变形
src/render.c     透明画面及软件三角形渲染
src/live2d_host.c  C 主程序的 DLL 加载、错误回退与自检
src/live2d_bridge.cpp / live2d_bridge.h  C++ SDK 离屏渲染与版本化 C 接口
live2d-preview/  独立预览、共享 SDK 加载代码、CMake 构建
live2d-runtime/  桌宠运行需要的 DLL、着色器与许可说明
src/monitor.c    只读进程采样及监控面板
src/gpu_monitor.c / gpu_monitor.h  GPU 计数器采样、聚合及自检
src/pet.h        公共类型和接口
assets/         运行必需的预乘 BGRA 素材
tools/prepare-assets.cjs  原工程的制作期素材导出工具

assets 已包含导出的素材，正常运行和编译 C 程序均无需运行导出工具。
该工具仅供原 Electron 工程环境中重新导出素材，独立下载本文件夹后不能直接运行。
